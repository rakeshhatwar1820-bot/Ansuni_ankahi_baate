# Ansuni Ankahi Bate - Android App Project (अनसुनी अनकही बातें)

Welcome! This is the complete, production-ready native Android Studio project for **Ansuni Ankahi Bate**.

### How to build APK in Android Studio (Free & Easy):
1. **Download & Extract** this ZIP on your computer.
2. **Open Android Studio** (Download free from developer.android.com if not installed).
3. Click **File -> Open...** and select the extracted folder `AnsuniAnkahiBate-Android-App`.
4. Wait for Gradle sync to complete (takes ~1 minute on first open).
5. **To Test On Phone or Emulator**:
   - Connect your Android phone with USB Debugging enabled, or start an Emulator.
   - Click the green **Run (▶)** button!
6. **To Generate APK for WhatsApp / Direct install**:
   - Click **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
   - Click "locate" when notified. Your `app-debug.apk` is ready to install or share!
7. **To Publish on Google Play Console**:
   - Click **Build -> Generate Signed Bundle / APK**.
   - Select Android App Bundle (.aab), create your release key, and upload to Google Play Console!
